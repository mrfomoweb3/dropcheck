The current cut uses on-screen storytelling and light sound effects. This script is ready for a voice pass; it is not an assertion that the Polkassembly author used Dropcheck.

0–9 s: A community post described DED tokens stuck on Asset Hub without enough DOT. It raises a simple question: what if we checked before sending?

9–14 s: That is the problem Dropcheck tackles for token distributions on Portaldot.

14–23 s: Paste a recipient list or upload a CSV. Dropcheck checks each row against live chain state and explains what it finds.

23–33 s: This fresh wallet has no native token. Dropcheck adds a zero point one one tPOT top-up to the plan. Review the fixes, connect your wallet, then use Fix and Send.

33–43 s: In a recorded browser test on Portaldot V3, one signed batch confirmed seventeen token transfers and five native top-ups. The block reference is in the project’s proof log.

43–48 s: Dropcheck. Check your airdrop before it ships.
