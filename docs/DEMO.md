# Demo runbook

1. No re-seeding needed: the 5 "fresh" rows are regenerated as brand-new accounts on every page load.
2. Record with your own wallet extension holding ~3 tPOT: Connect → **Create my demo token** → Fix & Send → sign →
   open the block link. (Or import the demo sender into your extension **yourself**, never via this repo/app; it
   already holds DROP, so the create step is skipped.)
3. Incognito → open URL → demo list pre-loaded and checked without a wallet (preview).
