# Demo runbook

1. `pnpm seed-demo` (new fresh rows each recording) → commit `public/demo.json` + `public/demo-list.csv` → deploy.
2. Import the demo sender into the wallet extension used for recording **yourself** (never via this repo/app).
3. Incognito → open URL → demo list pre-loaded → Fix & Send → sign → open the block link.
